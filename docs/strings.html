Strings

A String is UTF-8 text. Silica accepts four delimiter forms, and the triple-quoted ones may span lines.

delimiters.sc
sfn main() {
    let single: String = 'single quotes'
    let double: String = "double quotes"
    let block: String = """triple quotes
can span lines"""

    sprint(single)
    sprint(double)
    sprint(block)
    sprint("escape: tab\there, newline above, quote \" inside")
}
output

Concatenation, indexing and length

+ concatenates two strings; mixing a string and a number is a type error, so convert with str(), int() or float() first. Indexing with s[i] returns a one-character string, indexed from zero; len(s) gives the length in characters.

concat.sc
use string

sfn main() {
    let name: String = "Silica"
    let version: String = "0.9.0"
    sprint(name + " v" + version)
    sprint(string.trim("   padded   "))
    sprint(string.ends_with(name, "ica"))
    sprint(string.contains(name, "lic"))
}
output
Output

padded
oui

The string module

The string module must be imported with use string. Calling it without the import is a compile-time error that says so.

strings.sc
use string

sfn main() {
    let line: String = "silica,language,bytecode"
    let parts: List = string.split(line, ",")

    per part in parts {
        sprint(string.upper(part))
    }

    sprint(string.join(parts, " | "))
    sprint(string.replace(line, ",", " "))
    sprint(string.starts_with(line, "silica"))
    sprint(len(line))
    sprint(line[0])
}

What strings cannot do

There is no string interpolation and no template syntax in 0.9.0: build text with + and str(). There are also no regular expressions — regex is a planned module that currently fails to import with an explicit message.
