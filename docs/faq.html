FAQ

Short answers to the questions that come up most, including the ones where the answer is "no".

Is Silica fast?

No. On the repository's four benchmarks it ran 38–101× slower than CPython when measured on 2026-10-28, because the VM is a Python loop. Constant folding cut one hot loop by 39%. Speed is not the current goal; correctness and clarity are.

Is it production-ready?

No. It is an early 0.x release with a small standard library, no concurrency, no networking and no package manager. Use it to learn, to experiment, and to build small tools.

Can Silica compile itself?

Not yet. Self-hosting is a staged plan in the repository's bootstrap document, not a finished feature.

Does it have classes, structs or generics?

No. There are no user-defined types, no fields or methods, and no generic parameters — List and Map elements check as Any. These are on the roadmap.

Are there closures or first-class functions?

No. Functions can be called but not passed, returned or stored.

Does it support exceptions or a Result type?

No. A type error is caught before anything runs; a runtime error stops the program with a located message. Recoverable errors are written by hand, for example by returning a sentinel value.

Can it make HTTP requests or run a web server?

No. net, http and crypto are planned modules; importing one is a compile error that says so.

Which platforms work?

Linux x86_64 is the tested platform. Termux's code path is tested with its environment variables but has not been run on a device. macOS and Windows are not supported by the installer; pip install . should work because there are no compiled parts, but that is an expectation, not a verified claim.

Why does it need a capability to read a file?

Because Silica programs are untrusted by default. A program cannot read, write, open a window or use the terminal unless you grant exactly that capability, scoped to a directory. It is the same idea as a browser permission prompt, applied to a language.

Is it free? Can I use it commercially?

Yes. Silica is MIT licensed — Copyright (c) 2026 Umaiz Sufiyan. You may use, modify and redistribute it, including commercially, provided the copyright notice and permission notice are included.

How is it tested?

The repository runs its suite with python3 -m unittest discover -s tests -t .; on the audited commit that is 803 tests. CI runs it on Python 3.9, 3.11 and 3.12. Silica also has its own test runner for *_test.sc files: silica test tests.

Who made Silica?

Umaiz Sufiyan, an independent student developer. The project is developed in the open on GitHub, and contributions are welcome.

Why are the keywords not English?

Because the language was designed to have its own identity rather than imitate another one. si/sino, tant/per and oui/nein are the language's own vocabulary, and they are reserved words.

Something else

Still stuck? Open an issue on GitHub. Questions that turn into useful answers get added to this page.
