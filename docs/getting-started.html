    Getting Started

    Silica is a Python package with one console command, silica. This page takes you from nothing to a running program, then to bytecode and the in-browser IDE.

    Requirement: Python 3.9 or newer. The core language has no third-party dependencies, so nothing else is needed to run Silica programs.

    1. Install

    The installer downloads the release wheel for the current version, verifies its SHA-256 against SHA256SUMS.txt from the same release, and installs it into an isolated environment at ~/.local/share/silica/venv with a launcher in ~/.local/bin (or $PREFIX/bin on Termux).

    bash
    Terminal
    1 2 3
    curl -fsSL https://raw.githubusercontent.com/sufiyan-sabeel/silica/main/install.sh | sh
silica --version
silica 0.9.3

    If silica is not found afterwards, the installer prints the exact line to add to your shell profile. In short: export PATH="$HOME/.local/bin:$PATH".

    Other ways in — Termux, pip install from a checkout, a system-wide install — are on the Installation page.

    2. Your first program

    A Silica program lives in a .sc file. Every program needs a main function; that is where execution starts.

    hello.sc
    1 2 3
    sfn main() {
    sprint("Hello from Silica")
}
    output
    Output
    Hello from Silica

    Run it:

    bash
    Terminal
    1 2 3 4 5
    $ silica run hello.sc
Hello from Silica

$ silica hello.sc        # the same thing
Hello from Silica

    3. Check before you run

    check parses and type-checks without producing bytecode, which is the fastest way to find a mistake. It exits non-zero when it finds one.

    bash
    Terminal
    1 2 3
    $ silica check hello.sc
$ echo $?
0

    A diagnostic always names the file, line and column, and usually suggests a fix:

    output
    Real diagnostic
    1 2
    app.sc:2:18: type error: cannot initialise Int with a value of type String
  hint: convert explicitly with int(value)

    4. The interactive interpreter

    Run silica with no arguments for the interactive interpreter. Globals and functions persist between entries.

    bash
    Terminal
    1 2 3 4 5 6 7
    $ silica
Silica 0.9.3 — Ctrl+D to exit
> sprint("hello")
hello
> let x: Int = 2
> sprint(x * 21)
42

    5. Compile to bytecode

    Compiling writes a versioned .sbc file: a magic number, format version, CRC-32, constant pool, function metadata and a line table. The loader verifies it before anything executes.

    bash
    Terminal
    1 2 3
    $ silica compile hello.sc -o hello.sbc
$ silica run hello.sbc
Hello from Silica

    6. Try the Script Mode IDE

    The Script Mode IDE is a local editor and runner for .sc files. It serves a page on 127.0.0.1 and requires the session token it prints. The Run button executes the real toolchain in a subprocess.

    bash
    Terminal
    1 2 3 4 5
    $ silica ide --root ~/scripts
Silica Script Mode
  workspace : /home/you/scripts
  listening : 127.0.0.1:8080
  open      : http://127.0.0.1:8080/?token=<session-token>
