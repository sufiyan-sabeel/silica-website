Built-in Functions

Silica's standard library is a set of native functions grouped into modules. core is always in scope; everything else needs a use statement. Types in the tables below are the ones the static checker enforces.

core — always available

FunctionSignatureWhat it does
sprint(x)Any → Unitprint with a newline
dit(x)Any → Unitprint without a newline
input(prompt)String → Stringread one line of stdin
type_of(x)Any → Stringthe runtime type name
assert(cond, message)Bool, String → Unitabort if false
str(x) / int(x) / float(x)Any → String / Int / Floatexplicit conversion
len(x)Any → Intlength of a string, list or map
range(a, b, step)Int… → List1–3 arguments
push(list, value)List, Any → Unitappend in place
keys(map) / values(map)Map → Listmap contents
has(container, key)Any, Any → Boolkey or membership test

Example — type_of, str and len:

core.sc
sfn main() {
    let items: List = [1, 2, 3]
    sprint(type_of(items))
    sprint(len(items))
    sprint(str(42) + "!")
    sprint(has(items, 2))
}
output
Output
List
3
42!

math

Import with use math. math.pi, math.e and math.tau are constants, not functions.

FunctionReturns
math.abs(x)same type as the argument
math.min(a, b) / math.max(a, b)the smaller / larger value
math.sqrt(x)Float
math.pow(a, b)Float
math.floor(x) / math.ceil(x) / math.round(x)Int
math_demo.sc
use math

sfn main() {

    sprint(math.min(3, 8))
    sprint(math.max(3, 8))

    sprint(math.floor(3.99))
    sprint(math.ceil(3.01))
    sprint(math.round(2.5))

collections

Import with use collections.

FunctionReturnsNotes
collections.sort(list)Lista sorted copy
collections.reverse(list)Lista reversed copy
collections.index_of(list, value)Intposition, or -1
collections.sum(list)Anynumeric total
collections.sc
use collections

sfn main() {
    let nums: List = [5, 3, 9, 1]
    sprint(collections.sort(nums))
    sprint(collections.reverse(nums))
    sprint(collections.sum(nums))
    sprint(collections.index_of(nums, 9))

    let ages: Map = {"anita": 31, "rahul": 27}
    sprint(ages["anita"])
    sprint(has(ages, "rahul"))
    sprint(keys(ages))

    let bag: List = []
    push(bag, "apple")
    push(bag, "pear")
    sprint(bag)
}

json

Import with use json. The mapping is deliberate: oui/nein become true/false, null parses to Unit, and errors carry a position.

FunctionSignatureNotes
json.parse(text)String → Anyerrors report a position
json.stringify(value)Any → Stringcompact form
json.stringify(value, indent)Any, Int → Stringpretty-printed
json_demo.sc
use json

sfn main() {
    let settings: Map = {"width": 80, "ratio": 1.5, "wrap": oui, "tags": ["a", "b"]}
    let text: String = json.stringify(settings)
    sprint(text)

    let parsed = json.parse(text)
    sprint(type_of(parsed))
    sprint(parsed["width"])
    sprint(json.stringify(parsed, 2))
}
output

fs — behind capabilities

Import with use fs. Every function is behind a capability, and nothing is granted by default:

FunctionCapability required
fs.read_text(path)fs.read
fs.write_text(path, text)fs.write
fs.list_dir(path)fs.list
fs.exists(path)none — metadata only
bash
Granting a capability
$ silica run app.sc --allow-fs-read ./data --allow-fs-write ./out

# without the grant:
# capability error: 'fs.read' is not granted
#   hint: run with --allow-fs-read DIR

Modules

ModuleImportStatus
corealways in scopeimplemented
mathuse mathimplemented
stringuse stringimplemented
collectionsuse collectionsimplemented
jsonuse jsonimplemented
fsuse fsimplemented, capability-gated
ui, tui, gui, speechuse ui …implemented; UI namespaces are separate
path, time, random, regex, http, net, crypto—planned; importing is a compile error

Importing something that does not exist

A planned module is refused at compile time with a message that names it — it never pretends to load. For example, use net reports that the module is planned and not implemented. The list of planned modules is fixed in the source, so the message cannot drift from reality.
